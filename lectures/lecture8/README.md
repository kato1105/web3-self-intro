## 🧠 v3 からの進化ポイント

### 1. フィードバック収集機能（価値検証のコア）

- **アプリ内 NPS アンケート**
  - 「友人に薦めたいか？」を 0–10 で評価
  - 「継続して使いたいか？」を ⭐1–5 で評価
  - 「どんなシーンで使いたい？」「改善してほしい点は？」の自由記述
  - レポート 3 回投稿後に自動表示 or ヘッダーの「📝 評価」ボタンから手動表示

- **👍 / 👎 リアクションボタン**
  - 各スポットカードに設置し「この情報は役に立ったか？」をワンタップ評価
  - 集計結果をリアルタイム表示

- **📊 検証結果ダッシュボード**
  - サイドバーの「📊 検証結果」タブに NPS スコア・継続利用意欲・利用統計・ユーザーの声をビジュアル表示
  - 「📋 検証結果をコピー」ボタンで Discord 投稿用テキストを一発コピー

### 2. UI/UX の大幅改善

- **オンボーディングツアー**
  - 初回アクセス時に 4 ステップのガイドを表示
  - 「①場所検索 → ②スポット確認 → ③混雑報告 → ④トークン獲得」

- **ダーク / ライトモード切替**
  - ヘッダーの ☀️ / 🌙 ボタンでワンタップ切替
  - 地図タイルも連動してテーマ変更
  - ユーザー設定は localStorage に保存

- **マイクロアニメーション**
  - スポットカードのスタガードフェードイン
  - 報酬獲得・フィードバック送信時のコンフェッティ（紙吹雪）演出
  - ステータスバッジのパルスアニメーション

- **情報設計の改善**
  - 時間帯別混雑グラフ（簡易棒グラフ）をスポットカード内に表示
  - 「🟢 今すぐ行ける」タグで空きスポットを強調
  - 最終更新の鮮度をプログレスバーで視覚化

## 🔬 価値検証の方法

1. **プロダクトを使ってもらう**
   - 友人・クラスメイトに URL を共有し、実際に操作してもらう

2. **フィードバックを収集する**
   - アプリ内の NPS アンケートで定量評価を取得
   - 👍/👎 リアクションで情報価値を測定
   - 自由記述で利用シーン・改善点を収集

3. **検証結果を可視化する**
   - ダッシュボードで結果をリアルタイム集計
   - Discord 投稿用のフォーマットで結果を出力

## 🛠️ 技術スタック

- テーマシステム: CSS変数 + data-theme属性
- プロトタイプ: 単一HTMLファイルSPA（依存なし）
