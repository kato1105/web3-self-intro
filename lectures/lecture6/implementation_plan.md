# どこすわ？ v2 実装プラン

## 1. 現在の状況確認（lecture5／v2 完成版）

- すでに実装されている機能
  - 地名・駅名による手動検索で現在地を特定
  - 地図とスポットリストを連動させ、半径3km以内のスポットを抽出・距離順ソート
  - スポットごとに「Google Map 詳細リンク」を表示
  - ユーザーが混雑状況をワンタップ投稿できるモーダル
  - 投稿は `localStorage` へ保存し、30分以内の最新情報を表示
  - レスポンシブSPAデザインで PC/モバイル両対応

- 現状の課題
  - Web3 / トークンエコノミーはドキュメント上の説明のみで、UI/UX に直接表現されていない
  - AI 予測やおすすめ機能は未実装で、リアルタイム情報の不足感を補う体験が薄い
  - 「ウォレット接続」「報酬獲得」の演出がないため、DePIN 的な振る舞いが見えづらい

## 2. v2 の主な進化アイデア（提案）

### 2-1. Web3 トークンエコノミーの実装（DePIN モック）

- 画面上部に **「ウォレット接続」ボタン** を追加
  - クリックすると簡易モックでウォレット接続状態になる
  - 接続中は画面に `walletAddress` のプレースホルダーを表示

- ユーザーが混雑状況を投稿すると、
  - `+10 JOIN獲得！` などの報酬演出を表示
  - 報酬付きの投稿履歴を `localStorage` に保存
  - 画面にトークン残高（JOIN / ICHIGO）を表示

- 目的
  - 「トークンを得るために情報を投稿する」という行動インセンティブを体感できるようにする
  - Web3 風の UX をモックとして追加し、DePIN の価値仮説をユーザーが直感的に理解できるようにする

### 2-2. AI 混雑予測の追加

- スポットカードに **AI予測コメント** を追加
  - 例: `🤖 AI予測: 午後から混雑の可能性大`
  - 例: `🤖 AIおすすめ: 夕方は穴場になりそう`

- 画面に **AIおすすめフィード** を追加
  - 「AIがおすすめする混雑しにくいスポット」「この時間帯に狙い目」などの文言を表示
  - 現状はモックとしてステートに固定文を入れる

- 目的
  - リアルタイム混雑情報が少ないときでも、AIによる仮説的な価値を感じられる
  - AIアシスト型のサービス感を強化する

## 3. 実装方針（「どこすわ？」向け）

### 3-1. UI 追加・変更

- ヘッダーにウォレット接続エリア
  - `Connect Wallet` / `Connected` 表示
  - 獲得トークン残高：`JOIN: 0`、`ICHIGO: 0`

- 投稿モーダルに報酬演出
  - 投稿成功時に一時的なバナー `+10 JOIN 獲得！` を表示
  - 投稿が報酬アクションとしてわかりやすいアニメーション風演出

- スポットカード内に AI 予測情報
  - `AI予測` / `AIおすすめ` の吹き出しテキスト
  - 予測があることで「人力データ＋AI補完」の体験を出す

- サイドバー / 下部に AI おすすめセクション
  - `今日のAIおすすめ` などの固定UI
  - `「混雑が少なそうな時間帯」を提案` などの文言

### 3-2. データ構造

- `localStorage` の保存形式に追加
  - `reports` に `reward` や `submittedAt` を含める
  - `walletState` に `isConnected`, `address`, `joinBalance`, `ichigoBalance` を追加

- 例
  ```json
  {
    "walletState": {
      "isConnected": true,
      "address": "0x1234...abcd",
      "joinBalance": 120,
      "ichigoBalance": 500
    },
    "reports": [
      {
        "spotId": "spot-1",
        "status": "crowded",
        "comment": "混雑してる",
        "submittedAt": 1710000000000,
        "reward": 10
      }
    ]
  }
  ```

### 3-3. アクションの流れ

1. ユーザーが `Connect Wallet` を押す
2. 画面が `Connected` に変わり、仮のウォレットアドレスを表示
3. スポットの混雑状況を投稿
4. `+10 JOIN` の報酬バナーが表示され、トークン残高が更新される
5. スポットカードに AI 予測文が常時表示される

## 4. 開発の優先順位

1. `Connect Wallet` ボタン + モック接続状態
2. 投稿時の報酬演出とトークン残高表示
3. スポットカードへの AI 予測文追加
4. `AIおすすめ` セクションの UI と文言
5. README / Discord投稿文への反映

## 5. 作業メモ

- 既存の `lecture5/index.html` は単一ファイル SPA の構成なので、UI 追加は HTML と JS の最小差分で対応可能
- `localStorage` を活用するため、バックエンドは不要
- 今後の拡張として、本番実装では `wallet connect` を WalletConnect / MetaMask に置き換え可能
- AI機能は現状モックでも「プロダクトの差分を説明できる」価値が大きい

## 6. Discord 投稿向けまとめ（v2 差分）

- v1 からの差分:
  - 「ウォレット接続 → 投稿でトークン獲得」のトークンエコノミー演出
  - 「AI予測 / AIおすすめ」による混雑リスクと穴場案内の追加
  - 体験として「DePIN モック」と「AI補完」を見せる形に進化

- 提案効果:
  - ユーザーが混雑情報を投稿する動機を視覚化
  - リアルタイムデータ不足でも AI を使った補完体験を提示
  - Web3 と AI の両輪で「どこすわ？」の価値を拡張する
