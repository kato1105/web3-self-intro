## ⚙️ 実装された機能（v2 ミニマム版）

1. **手動位置検索 + 地図連動**
   - 地名や駅名を入力すると、地図がその場所へ移動します。
   - 検索結果に応じて周辺スポットの表示が切り替わります。
2. **現在地連動のスポット抽出と距離ソート**
   - 入力した地点から近い順にスポットを並べ替え表示します。
   - 各スポットカードに距離が表示され、移動予測感を強化します。
3. **混雑レポート投稿機能**
   - ユーザーが「空きあり」「普通」「混雑」を簡単に報告できる投稿モーダルを用意。
   - 投稿は localStorage に保存され、リアルタイム感のあるデータ表示を模擬します。
4. **Web3 / AI 体験のモック**
   - lecture6 では、`indexv2.html` で v2 の表記を強化し、Web3 と AI を感じられる試作としてまとめています。
   - Discord投稿用ドキュメントも `lecture6/discord-post.md` に追加しました。

---

## 💡 直面した技術的課題と、v2 の価値仮説

- **情報のリアルタイム性が弱い**
  - 本プロダクトでは、実データの取得が難しいため、ユーザー投稿をトリガーにした情報収集モデルを軸にしています。
- **Web3 トークンエコノミーのビジョン**
  - ユーザーが混雑状況を投稿すると報酬につながる、というインセンティブ設計を体験として提示することを目指します。
- **AI 補完の価値**
  - AI予測やおすすめ機能を加えることで、リアルタイム情報が不足している状況でもユーザーに安心感を提供できる構想です。
