## 🗣️ インタビューからの気づきと改善

### 第8回インタビューでの一番大きな気づき
> **「AI予測が当たっているのか不安。根拠がわからないと行動しづらい」**

### v4 → v5 での具体的な改善点

この気づきを踏まえ、「実際に使ってもらう（＝ユーザーが予測を信じて移動する）」ために以下の改善を行いました。

1. **AI予測に「信頼度（%）」と「根拠テキスト」を追加**
   - これまで「午後から混雑」という結果だけだった表示に対し、「過去の満席率」や「チェックイン数の傾向」などの具体的な理由を可視化。
   - スポットカードの予測部分に信頼度を示すバッジを追加しました。

2. **AI Insight（思考プロセス）モーダルの実装**
   - 予測部分をタップすると、AIがなぜその予測を出したのか詳細に説明するモーダルが表示されます。
   - 理由を明示することで、ユーザーの納得感と行動意欲を高める狙いがあります。

---

## 🛠️ 技術的な変更点

- `AI_PREDICTIONS` データ構造を単一の文字列から `{ text, reason, confidence }` のオブジェクトに変更。
- CSSでホバーエフェクトと `badge-confidence` を追加し、タップ可能なUIであることを強調。
- `openAiInsightModal` 関数を追加し、詳細情報をオーバーレイ表示するモーダルを実装。
