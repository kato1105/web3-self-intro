## 🛠️ v6 での実装・改善内容

最終発表（CHIBATECH PROTOTYPE）に向けて、より多くのユーザーに直感的に使ってもらえるよう、「Web3・トークン」という少しハードルが高い要素から**「独自ポイントシステム（どこすわポイント）」**へのピボットを行いました。

### 1. 「ウォレット接続」から「ログイン・ポイント」への変更
- これまで「ウォレット接続」としていたものを、一般的な「ユーザーログイン」に変更しました。
- 獲得する報酬も「JOIN トークン」から「どこすわポイント（pt）」に変更し、学習コストをゼロにしました。

### 2. 「特典ガチャ」機能の実装
- サイドバーに「🎁 特典」タブを新設。
- 報告で貯めたポイント（50pt）を消費して、お得なクーポンが当たる「ガチャ」を引くことができるようになりました。
- ガチャのアニメーションと、獲得したクーポンが一覧表示されるインベントリ機能を追加。
- これにより、**「探す → 報告する → ポイントが貯まる → クーポンをゲットする」** という完全な体験ループが完成しました。
