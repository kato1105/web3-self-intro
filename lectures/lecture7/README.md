## 🧠 v2 からの進化ポイント

1. **v2 の課題整理**
   - 混雑投稿の動機づけはまだ体験ベースが弱い
   - リアルタイム情報が足りない場合の安心感が不足している
   - 発表に向けて「見せたい相手」と「伝えたい価値」が曖昧だった

2. **v3 で目指す進化**
   - Web3 トークン報酬の演出を強化し、投稿行動の動機づけを明確化
   - AI 予測 / おすすめをより目立たせ、信頼感のある補完体験を追加
   - 最終発表で「誰に何を見せるか」を踏まえたストーリー設計を行う

---

## 🔧 v3 プロトタイプの設計方針

- **主な UX 強化**
  - `ウォレット接続` で報酬がもらえる体験を見える化
  - `AI予測` のメッセージで混雑リスクを提示
  - `投稿＋トークン獲得` のシームレスな流れを伝える
- **最終発表で伝えたい価値**
  - 「ユーザー主体のデータ収集」と「AI補完」が同一体験内で両立すること
  - Web3 トークンを使ったインセンティブ設計が、情報の自発提供を生むこと
  - 最終発表では、実際に動くプロトタイプと企画意図をセットで見せる

1. **対象観客**

   - 未来展望: DePIN 型の協調データインフラとトークンインセンティブ
