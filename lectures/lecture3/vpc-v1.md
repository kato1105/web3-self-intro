## 選択した課題（バグリスト #20）

> **勉強や作業をする場所を探しているとき、カフェや図書館の席の空き状況がわからず、現地に行って満席だとわかる。**

---

## Customer Profile

### Jobs（やりたいこと）
- ★ **快適に集中できる作業・勉強場所をすぐに確保したい**（最重要）
- 移動の無駄をなくして、限られた時間を有効に使いたい
- 混雑を避けて、静かな環境で作業したい

### Pains（困っていること）
- ★ **現地に行くまで席の空き状況がわからず、満席だと時間と体力を無駄にする**（最重要）
- カフェ・図書館・自習室ごとに情報がバラバラで一元管理できていない
- 混雑しやすい時間帯を把握していないため、ピーク時に無駄足を踏む

### Gains（得たいこと）
- ★ **目的地に到着する前に席が空いているか確認でき、確実に作業場所を確保できる**（最重要）
- 混雑状況や静かさのレベルも事前にわかり、目的に合った場所を選べる

---

## Value Map

### ★ Pain Relievers（課題解決策）
- リアルタイムの席の空き状況をアプリで確認できる機能
  - ユーザーの位置情報に基づき、周辺のカフェ・図書館・自習室の混雑度を地図上に表示
  - 「満席」「混雑」「空きあり」の3段階でひと目でわかるUIを提供
- 過去の混雑データをもとに「今から行っても大丈夫か」を予測して表示

### Gain Creators（価値提供）
- 目的別フィルター（Wi-Fi有無・電源コンセント・静音レベル・営業時間）で自分に合った場所を選べる
- 「今すぐ行ける空きのある場所」をワンタップで提案するクイックサーチ機能

---

## MVP（最初に作るプロダクト）

### 📱 スポット空き状況チェックアプリ「どこすわ？」

**概要:**  
現在地周辺のカフェ・図書館・自習室の混雑状況をリアルタイム表示するWebアプリ。ユーザーが実際に現地で「空いてた / 混んでた」を投稿し合う、クチコミ型の混雑マップ。

**最小機能:**
1. 位置情報取得 → 周辺スポットをマップ表示
2. ユーザーが「今の空き状況」を3段階（空き・普通・満員）でワンタップ投稿
3. 投稿から30分以内のリアルタイム情報を地図上のピンで可視化

**技術スタック（MVP）:**
- フロントエンド: HTML / CSS / JavaScript（Vanilla）
- マップ: Google Maps API または Leaflet.js
- バックエンド: Firebase（Firestore + 匿名認証）

**ターゲットユーザー:**  
大学生・フリーランサー・テレワーカーなど、外出先で作業場所を探すことが多い人
