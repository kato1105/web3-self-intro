## プロダクト概要

**「どこすわ？」** — 周辺のカフェ・図書館・自習室の混雑状況をリアルタイムで確認できるWebアプリ。

バグリスト #20 から着想:
> 勉強や作業をする場所を探しているとき、カフェや図書館の席の空き状況がわからず、現地に行って満席だとわかる。

---

## 動くもの（v1 最小スコープ）

- [x] Leaflet.js を使った地図表示（東京・渋谷周辺スポット）
- [x] 各スポットをピン（😊🟢 / 😐🟡 / 😓🔴）で表示
- [x] ユーザーが「今の空き状況」を3段階でワンタップ投稿
- [x] 投稿はlocalStorageに保存 → 30分以内のデータのみ表示
- [x] サイドバーにスポットリスト＋フィルター（空き・普通・混雑）
- [x] 現在地取得ボタン（位置情報API）
- [x] 統計バー（空き/普通/混雑の件数）

## 技術スタック

- HTML / CSS / Vanilla JavaScript
- Leaflet.js（地図表示）
- localStorage（報告データ永続化）
- Geolocation API（現在地取得）
- バックエンド不要 / Firebase 不要（プロトタイプのため）
